# IT-Desk UEM Public PKI Artifacts

This public repository is reserved for non-secret CA certificates, certificate revocation lists, integrity manifests, and their validation/publishing workflow.

It is intentionally separate from the private UEM application source. No private key, passphrase, credential, token, PFX/P12, CSR, endpoint identity, inventory, or manager configuration is permitted here.

The repository is currently in bootstrap state and contains no CA or certificate material.

## Security

Do not open a public issue with sensitive information. Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability-reporting channel when it is enabled.
